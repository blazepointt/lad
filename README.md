# Лад

**Лад** — персональное веб-пространство для дел, мыслей, времени и привычек. Всё в одном тёплом, спокойном месте: без аккаунтов, без серверов, без слежки. Данные живут только в вашем браузере.

```
npm install
npm run dev        # разработка → http://localhost:5173
npm run build      # продакшен-сборка в dist/
npm run preview    # локальный предпросмотр сборки
```

---

## Что внутри

| Раздел | Что умеет |
|---|---|
| **Главная** | Приветствие по времени суток, задачи и привычки на сегодня с быстрым вводом, фокус-время за день, ближайшие задачи, закреплённая заметка, цитата дня |
| **Задачи** | Добавление со сроком, приоритеты, заметки к задаче, фильтры «Активные / Выполненные / Все», поиск, группировка (Просрочено · Сегодня · Завтра · Позже), удаление с отменой («Вернуть») |
| **Заметки** | Карточки с цветами, закрепление, поиск, редактор с автосохранением, счётчик слов; пустая заметка не остаётся мусором |
| **Календарь** | Месячная сетка, задачи по дням, клик по дню — просмотр и быстрое добавление задачи на этот день |
| **Привычки** | Отметки по неделям, серии (текущая и лучшая), процент за 30 дней, 28-дневная мини-теплокарта, значки-эмодзи и цвета |
| **Фокус** | Таймер (15/25/50 или свой интервал), кольцо прогресса, пауза/продолжение, привязка раунда к задаче, мягкий звук по окончании, статистика и график за 7 дней. Отсчёт переживает перезагрузку страницы |
| **Инструменты** | Отсчёт до даты · генератор паролей (энтропия + копирование) · конвертер величин (длина, масса, объём, данные, температура) · проценты (скидки, чаевые, доли) · счётчики |
| **Настройки** | Имя для приветствия, темы, 6 акцентных цветов, начало недели, звук, длительности таймера, экспорт/импорт JSON, полная очистка |

Плюс: две темы (тёплая светлая и ночная — не инверсия), адаптив от телефона до десктопа, навигация через хэш (можно обновлять страницу и делиться ссылками на разделы).

## Принципы

- **Работает, а не выглядит.** Каждая кнопка что-то делает, всё состояние сохраняется мгновенно.
- **Приватность по умолчанию.** Ни одного запроса в сеть после загрузки: шрифты упакованы локально, данные — в `localStorage`.
- **Спокойный дизайн.** Бумажные тона, serif-заголовки (Lora), воздух, никакой кислоты.

## Стек и почему

- **React 18 + TypeScript** — компонентная модель и строгие типы для данных (задачи, привычки, заметки).
- **Vite** — мгновенный старт разработки и быстрая сборка; `base: './'` позволяет открыть `dist/index.html` прямо с диска.
- **CSS без фреймворков** — токены через CSS-переменные (`data-theme` / `data-accent` на `<html>`), ноль зависимостей в рантайме, полный контроль над темами.
- **Без библиотек дат/состояния** — свои ~100 строк (`src/lib/date.ts`) надёжнее и легче, чем тянуть date-fns ради форматирования; состояние — `useReducer` + Context.
- **Шрифты `@fontsource`** — Lora и Manrope собираются вместе с приложением, кириллица включена, офлайн работает сразу.

## Структура

```
src/
  App.tsx            каркас, навигация, темы-переключатель
  store.tsx          состояние + сохранение в localStorage
  types.ts           типы данных
  lib/               даты, хранилище, привычки, звук, цитаты
  components/        Icon (свой SVG-набор), Modal, Toast, Switch…
  pages/             Today, Tasks, Notes, Calendar, Habits, Focus, Tools, Settings
  styles/            global.css (токены и компоненты), pages.css (разделы)
```

## Данные и резервные копии

Состояние хранится в `localStorage` (ключ `lad.v1`), активный таймер — в `lad.run.v1`.
В «Настройках» есть экспорт всей базы в JSON-файл и импорт обратно — так данные переезжают между браузерами и устройствами.
